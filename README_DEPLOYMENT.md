# STARGATE CAFE PRO — دليل التثبيت والتشغيل والاختبار الكامل (Windows 11)
## الإصدار: v6.2.0 Next-Gen Edition (Emerald Luxury & Orders Hub)

---

### 1. المتطلبات الأساسية للنظام (System Prerequisites)
- نظام التشغيل: **Windows 10 / Windows 11 (64-bit)**
- بيئة التشغيل: **Python 3.10 أو أحدث** (موصى به: Python 3.12)
- متصفح: **Microsoft Edge** أو **Google Chrome** (يدعم نمط التطبيق المستقل App Mode).
- لا يلزم اتصال بالإنترنت أثناء التشغيل (يعمل 100% Offline، جميع المكتبات والأيقونات والخطوط مخزنة محلياً).

---

### 2. خطوات التثبيت النظيف (Clean Installation from Scratch)

افتح موجه الأوامر (PowerShell أو CMD) كمسؤول أو مستخدم عادي، ثم اتبع التالي:

```powershell
# 1. الدخول إلى مجلد المشروع المفكوك
cd C:\STARGATE_CAFE
# أو مجلد المشروع d:\STARGATE\organized_programs\cafe

# 2. إنشاء بيئة بايثون افتراضية نظيفة (Virtual Environment)
python -m venv venv

# 3. تفعيل البيئة الافتراضية
.\venv\Scripts\activate

# 4. ترقية pip وتثبيت جميع التبعيات المحددة
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. تشغيل جناح الاختبارات المؤتمت (Running Automated Tests)

لا يتطلب تشغيل الاختبارات أي برامج خارجية معقدة، حيث تم بناء الاختبارات بالاعتماد على مكتبة بايثون القياسية `unittest`، وتعمل على قاعدة بيانات SQLite اختبارية منعزلة تماماً دون المساس ببيانات المحل:

```powershell
# تفعيل البيئة إن لم تكن مفعلة
.\venv\Scripts\activate

# تشغيل الاختبارات الشاملة (20 اختباراً تغطي المحاسبة، الأمان، ومنع التكرار، ودورة الطلب)
python -m unittest tests/test_nextgen_pos_orders.py -v
```

**النتيجة المتوقعة:**
`Ran 20 tests in ~0.65s -> OK` (نجاح 20 من 20 اختباراً).

### 4. تشغيل خادم البرنامج (Starting the Server)

#### الطريقة الأولى (بضغطة زر):
- انقر نقراً مزدوجاً على الملف: **`تشغيل_برنامج_الكافيه.bat`**
- سيقوم السكربت بفحص المنفذ 5000، وتشغيل السيرفر في الخلفية، ثم فتح نافذة الكاشير على المتصفح تلقائياً.

#### الطريقة الثانية (يدوياً عبر الطرفية):
```powershell
.\venv\Scripts\activate
python app.py
```
ثم افتح المتصفح وتوجه إلى:
- **شاشة الكاشير (POS):** `http://127.0.0.1:5000/`
- **شاشة إدارة ومتابعة الطلبات (Orders Hub):** `http://127.0.0.1:5000/orders`
- **تسجيل دخول الموظف:** `http://127.0.0.1:5000/employee/login`

### 5. التحقق من صحة النظام المالي والأمان (Security & Financial Checklist)
1. **الذرية المحاسبية (Atomic Transactions):** كل عملية بيع أو إلغاء تنفذ داخل معاملة ذرية (`BEGIN IMMEDIATE`) مع التراجع التلقائي الكامل (`ROLLBACK`) في حال حدوث أي خطأ، دون ترك سجلات معلقة.
2. **منع التكرار (Server-side Idempotency):** يمنع الخادم تسجيل الفاتورة مرتين عند النقر المزدوج أو إعادة الإرسال عبر عمود `idempotency_key UNIQUE`.
3. **التسعير المعتمد (Authoritative Pricing):** يعيد الخادم جلب وحساب أسعار المنتجات والمخزون مباشرة من قاعدة البيانات، ولا يعتمد على الأسعار المرسلة من العميل.
4. **حماية الصلاحيات و CSRF:** جميع الطلبات التي تغير الحالة محمية برمز CSRF ولا تقبل التنفيذ إلا للمستخدمين المصرح لهم.
5. **الطباعة غير المؤثرة مالياً:** إعادة طباعة الإيصال الحراري 80mm أو الفاتورة الكاملة A4 هي للقراءة فقط ولا تنشئ أي حركة مالية جديدة.
